# EnterpriseERP Cloud i18n

EnterpriseERP Cloud uses `i18next` in both the web app and the API.

## Frontend

Main files:

- `apps/web/src/shared/i18n/I18nProvider.tsx`
- `apps/web/src/shared/i18n/LanguageSwitcher.tsx`
- `apps/web/src/shared/i18n/dictionaries.ts`

The existing application code can continue to use:

```tsx
const { locale, setLocale, t } = useI18n();
```

`I18nProvider` now delegates translation to `i18next` and `react-i18next`, while keeping this small project-specific API for easier migration.

## Backend

Main files:

- `services/api/src/common/i18n/i18n.module.ts`
- `services/api/src/common/i18n/i18n.service.ts`
- `services/api/src/common/i18n/i18n.controller.ts`
- `services/api/src/common/i18n/i18n.resources.ts`

Public API endpoints:

- `GET /api/i18n/languages`
- `GET /api/i18n/resources`
- `GET /api/i18n/resources/:locale`

## Supported Languages

- French: `fr`
- English: `en`
- Swedish: `sv`
- German: `de`
- Spanish: `es`
- Portuguese: `pt`
- Italian: `it`
- Dutch: `nl`

## Adding a New Translation Key

1. Add the French source key in `dictionaries.fr`.
2. Add the English and Swedish values in `dictionaries.en` and `dictionaries.sv`.
3. Add a short override for each additional language when the key is visible on public or high-traffic screens.
4. Use `t("your.key")` in React components.
5. Run `npm run qa`.

## Adding a New Language

1. Extend the `Locale` type and `locales` array.
2. Add its label to `localeLabels`.
3. Add an empty object in `dictionaries`.
4. Build the language with `buildLocale("en", { ...overrides })`.
5. Add the language in `services/api/src/common/i18n/i18n.resources.ts`.
6. Run `npm run qa`.
